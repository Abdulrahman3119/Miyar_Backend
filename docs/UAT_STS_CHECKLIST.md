# قائمة سيناريوهات UAT / STS — منصة معيار (Pilot)

**المصدر:** BRD v2.0 القسم 5 + ملحق الحالات STS  
**خارج النطاق:** SMS / دفع / نفاذ  
**آخر تحديث:** 2026-09-19

شغّل الاختبارات الآلية أولاً:

```bash
bench --site <site> execute miyar.tests.permission_matrix.run
bench --site <site> execute miyar.tests.delegation_matrix.run
```

## 1) صلاحيات (ملحق 7.1)

| # | السيناريو | متوقع |
| --- | --- | --- |
| P1 | Supervisor يحاول إنشاء طلب / تفويض / تشغيل محرك | رفض API |
| P2 | Lab Employee بدون تفويض يرى طلبات المنشأة كاملة | لا — فقط المفوض له |
| P3 | Support يخفي تقييم (STS07) | نجاح؛ حذف STS08 يفشل |
| P4 | Admin يحذف تقييم (STS08) | نجاح |
| P5 | بعد Logout، نفس `api_key/api_secret` | فشل مصادقة |

## 2) طلبات واختبارات

| # | السيناريو | STS / B.R. |
